# CLA signatures

The signatures of the [Contributor License Agreement](https://github.com/A79-ai/ampup-memory/blob/main/CLA.md),
written by the CLA workflow (`.github/workflows/cla.yml` on main) when a contributor signs it on a pull request.
Nobody edits this branch by hand. `signatures/v1/cla.json` holds the signatures of version 1 of the CLA.
