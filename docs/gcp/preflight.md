# What `memstore preflight gcp` checks

Generated by `memstore preflight gcp --explain`; edit `src/preflight.rs`, not this file.

Every check is read-only: it runs `gcloud` as you, prints each command first, and creates, changes and sends nothing. Outcomes: **FAIL** stops the install until fixed and always carries the fix; **WARN** says what to expect; **PASS** says what was found; **SKIP** says what couldn't be read. Exit code 0 all pass, 1 warnings only, 2 any failure, 3 the preflight itself couldn't run. `--json` writes the same rows as `{id, outcome, found, required, fix, doc}`.

| Check | Reads | FAIL or WARN when | Fix |
|---|---|---|---|
| `tools` | `gcloud --version`, `terraform version` | `gcloud` is missing (FAIL); `terraform` is missing or older than 1.5 (WARN: Cloud Shell has both) | install the Google Cloud CLI and Terraform, or run from Cloud Shell |
| `auth` | `gcloud auth list` | no account is signed in | `gcloud auth login` |
| `project` | `gcloud projects describe` | the project doesn't exist, can't be read, or isn't ACTIVE | check the id, or ask for Viewer on it |
| `billing` | `gcloud billing projects describe` | no active billing account is linked (FAIL); it can't be read (SKIP: needs `billing.resourceAssociations.list`) | link a billing account in the console |
| `api` | `gcloud services list --enabled`, against the APIs the template enables | an API is off and you can't enable it (FAIL); off but the template will enable it when you apply (WARN) | `gcloud services enable <api> --project <project>` |
| `org-policy` | `gcloud resource-manager org-policies describe --effective`, one row per constraint | domain-restricted sharing excludes the vendor's customer id; `run.allowedIngress` forbids internal; `gcp.resourceLocations` excludes the region. External IPs or shielded VMs enforced are WARN (Cloud NAT and the template's node settings handle them); SA key creation disabled is PASS (memstore makes none) | an exception on the project for the named constraint, by whoever administers org policies |
| `quota` | `gcloud compute regions describe` (limit and usage) and `gcloud quotas info list` (limit) for the region | limit minus usage is below what the chosen size needs | request an increase from the console's Quotas page for the named quota, or choose another region |
| `names` | the bucket, the engine's service account, the `<name>-engine` service, the `<name>_api` dataset and the vendor custom roles (including deleted ones) | the bucket name belongs to someone else (FAIL); a resource by that name already exists (WARN: `init` adopts it) or a custom role id was deleted in the last 37 days (WARN: choose another `name`) | another `-var bucket=` or `-var name=` |
| `egress` | a TCP connect to the control plane and the image registry on 443, from this shell | a host can't be reached (WARN: this shell isn't the VPC; nodes need Cloud NAT or a proxy to the same hosts) | allow outbound 443 to the named hosts from the subnet |
| `region` | `gcloud compute regions describe` (status) and `gcloud run regions list` | the region is DOWN, or Cloud Run doesn't serve it | `-var region=` another region |
| `permissions` | `testIamPermissions` on the project for what applying the template needs | you lack one (WARN: the person who applies the template needs them all) | ask for Owner on the project, or Editor plus Project IAM Admin, Role Administrator and Service Account Admin |

## Org-policy constraints read

| Constraint | What it means for memstore |
|---|---|
| `iam.allowedPolicyMemberDomains` | domain-restricted sharing: the vendor principal must be allowed |
| `iam.disableServiceAccountKeyCreation` | memstore creates no service account key |
| `iam.disableCrossProjectServiceAccountUsage` | memstore attaches no service account from another project; the vendor impersonates one made here |
| `compute.vmExternalIpAccess` | GKE nodes get no external IP; the template makes Cloud NAT |
| `compute.requireShieldedVm` | the template's nodes are shielded |
| `compute.restrictVpcPeering` | BYOC makes no peering |
| `compute.skipDefaultNetworkCreation` | the template makes its own network |
| `run.allowedIngress` | the engine is `internal` ingress |
| `gcp.resourceLocations` | every resource is in the chosen region |
| `storage.uniformBucketLevelAccess` | the bucket uses uniform access |
| `storage.publicAccessPrevention` | the bucket prevents public access |

## Permissions the template's applier needs

- `resourcemanager.projects.setIamPolicy`
- `serviceusage.services.enable`
- `iam.roles.create`
- `iam.roles.update`
- `iam.serviceAccounts.create`
- `iam.serviceAccounts.setIamPolicy`
- `storage.buckets.create`
- `storage.buckets.setIamPolicy`
- `bigquery.datasets.create`
- `compute.networks.get`

## Quota the team size needs

Cloud Run: 7 vCPU of `run.googleapis.com/cpu_allocation` in the region. GKE: 12 `N2_CPUS`, 300 `SSD_TOTAL_GB`, 2 `IN_USE_ADDRESSES` in the region.
